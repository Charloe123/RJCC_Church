# Advanced Membership Module Prompt — Resurrected Jesus Christ Church Management System

Add a complete advanced membership and demographics management module to the self-hosted offline-first church management application for Resurrected Jesus Christ Church.

The system must work completely offline and synchronize updates only when internet becomes available.

Design the module using a modern black-and-white premium dashboard UI with mobile-first responsiveness.

## Personal Information

* Gender

  * Female
* Date of Birth
* National ID / Passport
* Phone Number
* Alternative Phone Number
* Email Address
* Physical Address
* City
* Branch/Campus

Add marital management functionality.

## Marital Status Options
